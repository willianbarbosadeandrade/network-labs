# Network Labs

Laboratórios práticos de redes construídos no **Cisco Packet Tracer**, acompanhando minha trilha na **Cisco Networking Academy**.

Trabalho com infraestrutura de LED e broadcast sobre redes IP na beIN MEDIA GROUP, em Doha. Aqui documento a teoria por trás do que uso na prática: cada lab traz a topologia, o plano de endereçamento, os comandos aplicados, como verifiquei que funcionou e o que aprendi.

## Como cada lab está organizado

```
labs/NN-nome-do-lab/
├── README.md        objetivo, topologia, endereçamento, configuração, verificação e aprendizados
├── topologia.png    captura da topologia no Packet Tracer
└── lab.pkt          arquivo do Packet Tracer, para abrir e testar
```

O modelo usado em todos os labs está em [`_modelo/README.md`](_modelo/README.md), e as convenções de endereçamento e nomes estão em [`docs/convencoes.md`](docs/convencoes.md).
