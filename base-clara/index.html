O que muda em IPv4, IPv6 e MAC?

A matemática é a mesma. O que muda é a largura de cada bloco e a forma escolhida para escrevê-lo.

IPv4 usa quatro octetos decimais

Cada bloco tem 8 bits. Com 8 bits existem 256 combinações, por isso os valores vão de 0 a 255.

💡256 combinações não significa valor 256. Como a contagem começa em zero, o último valor é 255.
OctetoDecimalBinário (8 bits)Hex

IPv6 usa oito hextetos

Cada bloco tem 4 dígitos hexadecimais, ou 16 bits. O endereço completo soma 128 bits.

💡O limite 255 não vale aqui. Um hexteto vai de 0000 a FFFF, isto é, de 0 a 65.535.
HextetoBinário (16 bits)Decimal

Forma comprimida: 2001:db8::ff00:42:8329. O :: substitui uma sequência de blocos zero e só pode aparecer uma vez.

MAC usa seis octetos hexadecimais

Cada par hexadecimal representa os mesmos 8 bits de um byte. Seis pares formam um endereço de 48 bits.

💡Hexadecimal não é outra eletricidade. É só uma escrita mais curta para os bits: 1A e 00011010 representam o mesmo valor.
